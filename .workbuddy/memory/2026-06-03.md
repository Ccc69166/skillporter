# 2026-06-03 SkillPorter 更新日志

## 完成的工作

### 1. 重组 platforms 目录结构
- 将原有的 flat 结构改为子文件夹结构
- 每个平台有独立的子文件夹，包含 parser.py 和 renderer.py
- 更新了所有导入路径，使用绝对导入

### 2. 添加 7 个新平台支持
- **CodeBuddy**: 与 WorkBuddy 完全兼容
- **Cursor**: 支持 .cursorrules 和 .cursor/rules/*.mdc 格式
- **Cline**: 支持 .clinerules/*.md 格式
- **KiloCode**: 支持 .kilo/rules/*.md 格式
- **Kimi Code Agent**: 与 Claude Skills 兼容
- **通义灵码CLI**: 与 Claude Skills 兼容
- **Hermes**: 支持 hermes.yaml 配置格式

### 3. 移除 CLI 相关代码
- 删除了 cli.py 和 __main__.py
- 更新了 __init__.py，移除 CLI 导入
- 项目现在仅支持 GUI 模式

### 4. 更新 GUI 平台配置
- 在 convert_panel.py 的 PLATFORMS 字典中添加了所有新平台
- 总共支持 10 个平台

### 5. 更新版本号
- 从 v2.0.0 更新到 v2.1.0

## 技术细节
- 使用绝对导入替代相对导入，解决模块导入问题
- 每个平台的 parser 和 renderer 都遵循统一的基类接口
- 新平台支持多种格式：YAML配置、Markdown+YAML前言、纯文本规则

## 测试结果
- 所有平台的 parser 和 renderer 都能正常导入
- GUI 平台配置正确加载
- 项目整体能正常运行
